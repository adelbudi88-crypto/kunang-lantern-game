**Kunang — Lantern of the Night Garden.** You are the firefly spirit guarding the garden lantern. Fly through a moonlit night garden, gather dew-light to keep your lantern burning, chain orbs into combos up to ×8, dodge shadow moths and thorn brambles, and grab power-ups (shield, slow time, magnet) as the night grows faster and hungrier. Three lives — when the light dies, so does the night.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

No build step, no dependencies, no network: vanilla JavaScript + Canvas 2D, all art drawn in code, all sound synthesized live with WebAudio.

Controls: **WASD / arrow keys** or **mouse** to fly · **P / Esc** pause · **R** restart · **M** mute · **Space / click** start.
